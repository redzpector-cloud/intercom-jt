# Jejak Teknisi Mesh Intercom V1

Fondasi aplikasi Android untuk interkom lokal.

Target V1:
- 2 HP
- permission microphone + nearby devices
- UI status koneksi
- struktur siap dikembangkan menjadi audio real-time
- fondasi berikutnya: discovery, socket audio, multi-hop mesh, auto reconnect, internet fallback

Catatan:
V1 ini adalah kerangka aplikasi yang dapat dibuild. Mesin audio/network real-time belum dipalsukan sebagai sudah selesai; modul tersebut akan ditambahkan pada tahap implementasi berikutnya.
